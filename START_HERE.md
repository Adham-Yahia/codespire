## 🗄️ MongoDB Setup

### Option 1: Local MongoDB (Quick Test)
```powershell
# Install MongoDB from: https://www.mongodb.com/try/download/community
# Then start it:
mongod
```

### Option 2: MongoDB Atlas (Recommended - No Installation)
1. Go to https://mongodb.com/atlas
2. Create free account (M0 Free Tier)
3. Create cluster
4. Get connection string
5. Update `.env`:
   ```env
   MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/codespire
   ```

### Option 3: Skip MongoDB (For Now)
The server will start but database operations won't work until MongoDB is connected.

## 🧪 Test the API

### 1. Check if server is running:
```powershell
# In PowerShell:
Invoke-RestMethod http://localhost:5000

# Or in browser:
# Open: http://localhost:5000
```

### 2. Register a test user:
```powershell
$body = @{
    name = "Test User"
    email = "test@example.com"
    password = "test123"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5000/api/auth/register" `
    -Method POST -Body $body -ContentType "application/json"
```

### 3. Login:
```powershell
$body = @{
    email = "test@example.com"
    password = "test123"
} | ConvertTo-Json

$response = Invoke-RestMethod -Uri "http://localhost:5000/api/auth/login" `
    -Method POST -Body $body -ContentType "application/json"

# Save the token
$token = $response.data.token
```

### 4. Get your profile:
```powershell
Invoke-RestMethod -Uri "http://localhost:5000/api/auth/me" `
    -Method GET -Headers @{Authorization = "Bearer $token"}
```

**Success!** 🎉 Your API is working!

## 🐛 Troubleshooting

### Server won't start?
```powershell
# Re-run setup
npm run setup

# Check if port 5000 is busy
netstat -ano | findstr :5000

# Try a different port (edit .env)
PORT=5001
```

### MongoDB connection failed?
```powershell
# Option 1: Start local MongoDB
mongod

# Option 2: Use MongoDB Atlas (no installation needed)
# Update MONGO_URI in .env with Atlas connection string
```

### Can't run PowerShell script?
```powershell
# Enable script execution (one-time)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Need to regenerate .env?
```powershell
# Delete existing .env
Remove-Item .env

# Run setup again
npm run setup
```
