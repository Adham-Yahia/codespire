# ⚡ Backend Quick Start - Windows Edition

## 🎯 Three Ways to Get Started

### 1️⃣ Easiest: Run Setup Script (Recommended) ✨

```powershell
# One command does everything!
npm run setup

# Then start the server
npm run server
```

**What `npm run setup` does:**
- ✅ Creates `.env` file automatically
- ✅ Generates secure JWT secret
- ✅ Sets up local MongoDB connection
- ✅ Configures all defaults
- ✅ **No manual file editing needed!**

---

### 2️⃣ Even Easier: PowerShell Script 🪄

```powershell
# Run the quick-start script
.\quick-start.ps1
```

**What this does:**
- ✅ Installs dependencies if needed
- ✅ Runs setup if `.env` is missing
- ✅ Checks MongoDB status
- ✅ Starts the server automatically

---

### 3️⃣ Manual Setup (Traditional)

```powershell
# Install dependencies
npm install

# Copy environment file
Copy-Item .env.example .env

# Edit .env (add JWT secret)
notepad .env

# Start server
npm run server
```

## 🎓 Testing the API (PowerShell)

### Quick Test
```powershell
# Test if server is running
Invoke-RestMethod http://localhost:5000
```

### Register User
```powershell
$body = @{
    name = "Test User"
    email = "test@example.com"
    password = "test123"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:5000/api/auth/register" `
    -Method POST `
    -Body $body `
    -ContentType "application/json"
```

### Login & Save Token
```powershell
$body = @{
    email = "test@example.com"
    password = "test123"
} | ConvertTo-Json

$response = Invoke-RestMethod -Uri "http://localhost:5000/api/auth/login" `
    -Method POST `
    -Body $body `
    -ContentType "application/json"

$token = $response.data.token
```

### Get Profile
```powershell
Invoke-RestMethod -Uri "http://localhost:5000/api/auth/me" `
    -Method GET `
    -Headers @{Authorization = "Bearer $token"}
```

## 🐛 Common Issues & Solutions

### Issue: "npm run setup" command not found
```powershell
# Make sure you're in the project root
cd d:\MyWork\CodeSpire

# Run setup
npm run setup
```

### Issue: MongoDB not installed
**Use MongoDB Atlas instead!**
1. Create free account at https://mongodb.com/atlas
2. Get connection string
3. Update `.env`:
   ```env
   MONGO_URI=mongodb+srv://user:pass@cluster.mongodb.net/codespire
   ```

### Issue: Server won't start
```powershell
# 1. Check if port 5000 is busy
netstat -ano | findstr :5000

# 2. Kill the process or change port
# Edit .env and set: PORT=5001

# 3. Re-run setup
npm run setup
```

### Issue: PowerShell script won't run
```powershell
# Allow script execution (one-time setup)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Then run the script
.\quick-start.ps1
```
